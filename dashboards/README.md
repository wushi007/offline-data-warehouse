# 电商分析看板

[下载 HTML](https://github.com/wushi007/offline-data-warehouse/raw/refs/heads/main/dashboards/trade_funnel_dashboard.html)，保存后用浏览器打开即可。
GitHub 文件页展示的是源代码，不会直接运行 HTML。

单文件离线看板，图表库、字体和汇总数据均内嵌，不需要联网、Python 服务或数据库连接。文件约 11MB，浏览器直接打开 `file://` 即可使用。

## 页面

- **经营概览**：全部/10 月/11 月三个范围；购买记录金额、活跃用户、购买用户、购买会话键、购买用户占比。点击指标切换每日趋势，另有品牌/商品/品类排名、61 天每日明细和 CSV 导出。
- **用户分析**：月度活跃与购买用户、10 月买家在 11 月的再次购买占比，以及汇总 CSV。
- **商品表现**：窗口内全部 206,876 个商品的浏览、加购、购买用户数和记录金额；支持商品 ID 搜索、四种排序、“有浏览未观察到购买”筛选、20 行分页和全量筛选结果导出。
- **价格分析**：按事件价格划分的五个区间，切换金额占比/记录数占比，提供明细和 CSV 导出；零价与排除价格单独说明。
- **进阶分析**：RFM 八分群与 R×F 四格分布、严格 24 小时漏斗、GMV 代理变化分解；明细默认折叠，CSV 导出保留。

## 数据口径

- 覆盖 2019-10-01～2019-11-30 共 61 天，来自源数据的聚合快照，页面不会自动获取后续数据。
- 金额是购买记录金额，不是业务系统的独立订单数或销量，币种未确认。
- 用户与购买会话键按所选窗口独立去重；每日或每月数值不能直接相加，购买用户占比按窗口计算。
- 11-15 未观察到购买日志，原因未确认；零记录不代表已确认的零销售。
- 漏斗按 user×product 在 24 小时内严格匹配；源数据本身存在购买大于加购等倒挂现象，比例需要结合数据质量说明阅读。
- 网页与 CSV 只含聚合结果，不含 user_id、user_session 或源文件路径。

看板数据来自源数据聚合快照，不是本仓库 ADS 表的实时查询结果，也不是实时业务系统。图表库的许可证说明保留在 HTML 内。
